# HotWireStudio.2
VectorCAM-2D Studio FoamCutter

Векторный CAM-редактор для станков 2D hotwire (резка пенопласта нагретой проволокой)

HotWire Studio — это браузерное приложение для подготовки управляющих программ (G-code) для станков термической резки пенопласта. Работает полностью офлайн, в одном HTML-файле, без установки и бэкенда. Ориентировано на мастерские, где нужно быстро превратить чертёж в УП без изучения промышленного CAM-софта.

---

✨ Что внутри

Векторный редактор

· Полный набор 2D-инструментов: ручка с кривыми Безье, отрезок, дуга по центру, прямоугольник, эллипс, многоугольник (вписанный в окружность).
· Правка формы: узлы, сглаживание, скругление углов, нож (разрез и смыкание двух замкнутых контуров), смыкание векторов, удаление сегментов.
· Трансформации: поворот с шагом 5°, масштаб от закреплённой точки, зеркалирование относительно вертикальной оси.
· Булевы операции: объединение, вычитание, пересечение (алгоритм Greiner–Hormann).
· Массив копий: прямоугольный и полярный, с диалогом параметров.

Инженерные инструменты

· Отступ (offset) с типами угловых соединений — острый / круглый / фаска, лимитом miter и удалением самопересечений с вставкой узлов в точках пересечения.
· Линейка — расстояние, угол, диаметр по 3 точкам, длина сегмента, периметр.
· Вспомогательные направляющие — горизонтальные, вертикальные, наклонные (с произвольным углом). С перетаскиванием за ручку, привязкой к OSNAP и скрытием вместе с сеткой.
· OSNAP в стиле AutoCAD: конечные точки, середины, центры, квадранты, пересечения, перпендикуляры, касательные, ближайшая точка. Визуальные маркеры с подписями и свитч для их скрытия.
· Линеаризация дуг и Безье с настраиваемым допуском.
· Группы, слои, порядок резки — перетаскиванием строк.

Мозаика (nesting) v3

Собственный алгоритм раскладки деталей по листам:

· BLF по вершинным кандидатам с «гравитацией» (бинарный поиск максимального сдвига до реальных контуров);
· произвольный шаг поворота (0 / 90 / 45 / 30 / 15 / 10 / 5°, до 72 положений);
· доводка углов ±δ/±2δ после основной укладки;
· компакция листов (2 прохода);
· зеркалирование деталей;
· 5 детерминированных стратегий сортировки по реальной площади (shoelace) + seeded-перестановки;
· коллизии — по контурам, упрощённым Дугласом–Пекером (≤64 вершины), с технологическим буфером;
· асинхронный расчёт с прогресс-баром, лимитом времени и отчётом по листам и заполнению.

Управляющая программа

· G-code для 2D hotwire: подача/холостой ход, команды включения и выключения проволоки, задержка прогрева, компенсация пропила (kerf) снаружи/внутри, реверс, врезка через точку, привязка к нулю, отступ от края, произвольные prefix/suffix.
· Шаблон имени файла с плейсхолдерами: {date}, {time}, {seq}, {project}, {material}, {user}, {contours}, {sheet} и др.
· Сохранение в папку через File System Access API (Chrome/Edge) с fallback на обычную загрузку.
· Симуляция G-code: пуск/пауза, перемотка, скорость 1…60×, подсветка пройденного пути.
· Псевдо-3D в ISO — замкнутые контуры как тела заданной толщины.

Калькулятор резки пенопласта

· Физическая модель нагрева нихрома: сопротивление, ток, мощность, температура.
· Расчёт скорости резки от толщины листа, плотности пенопласта и параметров проволоки.
· График v(h), рекомендованное напряжение, ширина пропила, статус режима (недогрев / оптимум / перегрев).

Управление проектами

· Каталог проектов на localStorage с превью (SVG-миниатюра), поиском, сортировкой, видом сетка/список.
· Автосохранение каждые 600 мс, страховка каждые 30 сек и при закрытии вкладки.
· Диалоги в стиле iOS, суточные счётчики, шаблоны имён.

🛠 Технически

· Один HTML-файл. Ни сборки, ни зависимостей (кроме опциональных шрифтов и Chart.js для графика).
· Vanilla JS, ES5+ совместимость.
· SVG-рендеринг с vector-effect="non-scaling-stroke" и статичными по размеру маркерами.
· Геометрия без внешних библиотек: булевы операции, offset, Bezier, RDP, коллизии, мозаика — всё написано с нуля.
· Импорт: SVG (с viewBox, transform-матрицами, дугами), DXF (LINE, ARC, LWPOLYLINE с bulge, CIRCLE, ELLIPSE, SPLINE), EPS/PostScript.
· Экспорт: SVG, G-code, JSON-проект.
· Хранение: localStorage — каталог проектов, шаблоны имён, настройки OSNAP/мозаики/отступа, направляющие.
· Дизайн-система: CSS-переменные, единая типографика Inter + JetBrains Mono.

---

🚀 Запуск

Открыть index.html в браузере. Всё.

Для полного набора функций (сохранение в папку) — Chrome или Edge последних версий.

🗺 Что планируется

· Тёмная тема и настраиваемый размер UI.
· Экспорт DXF и PDF — для передачи в цех и печати техкарты.
· Command palette (Ctrl+K) — быстрый поиск по командам.
· PWA + Service Worker — работа в мастерской без интернета.
· Массивы по пути, текст с переводом в контуры.
· Умные направляющие (Smart Guides) и привязка к пересечениям/перпендикулярам в реальном времени.
· Профили станков с быстрым переключением.
· Рефакторинг в модули с canvas-рендером для больших проектов.

---

💡 Кому подойдёт

· Частным мастерским, которые режут крылья для RC-моделей, декоративные панели, упаковку, элементы архитектурного моделирования.
· Мейкерам, у которых есть ЧПУ-станок с горячей проволокой, но нет времени/денег на промышленный CAM.
· Инженерам для быстрой проверки идеи: нарисовал, разложил, посмотрел G-code, симулировал.
